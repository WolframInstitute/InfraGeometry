## Usage

`HomotopyMoveType[walk1, walk2]` classifies the elementary move walk1 -> walk2 as "Contract" (walk shortens), "Extend" (walk lengthens), or "Lateral" (walks have the same length; only possible for moves that swap arcs of equal length on an even-length null-homotopic cycle).
