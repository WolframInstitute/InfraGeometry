## Usage

`CompleteInfraEquilateralTriangle[graph, p1, p2]` returns the vertex list {c1, c2, ...} of the apex vertices equidistant from p1 and p2 at distance d(p1, p2) (Euclid I.1).

## Details & Options

Option: Method ("Metric" (default)).

The count argument n / UpTo[n] / All (default) picks realisations, exact n failing with $Failed.
