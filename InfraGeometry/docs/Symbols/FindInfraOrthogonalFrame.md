## Usage

`FindInfraOrthogonalFrame[graph, c, axisLength]` returns one frame of mutually perpendicular InfraSegment axes through c (axisLength = All | n | UpTo[n] | {min, max}); a trailing n / UpTo[n] / All controls the frame count.

## Details & Options

For the no-centre form use FindInfraSpanningAxes.

Options Method, "AxisCount", "BranchSampleSize", "SelectCoordinate".
