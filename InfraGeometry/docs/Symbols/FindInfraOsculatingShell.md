## Usage

`FindInfraOsculatingShell[graph, path, i, k]` returns shells whose level set contains the k-vertex window centered on path[[i]], one per osculating center, sorted by ascending radius; n / UpTo[n] / All controls multiplicity.

## Details & Options

Forwards Properties and "NextVertexFunction" to FindInfraSphere.
