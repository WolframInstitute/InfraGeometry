## Usage

`FindTarskiCounterexample[graph, predQ]` returns one vertex tuple witnessing the failure of the Tarski axiom predicate predQ, or $Failed.

## Details & Options

Returns $Failed for always-True axioms and TarskiContinuityQ.

With n / UpTo[n] / All caps witness count.
